# NEXUS visual references

The SVG in this folder is an original, editable vector reference for the intended desktop Overview workspace.

- `nexus-overview-reference.svg`: dark institutional terminal composition, compact navigation, instrument context, research status, chart workspace and evidence-oriented cards.

Important: this is a visual direction reference, not a claim that these screens or data connections are implemented. The chart is illustrative. The actual product must use verified data and real functional controls.

Visual rules:
- Obsidian #080B12 and Graphite #111827 foundations.
- Restrained Gold #C6A15B and Neural Cyan #36C9D6 accents.
- High contrast, compact hierarchy and meaningful whitespace.
- Research status and sample size must remain visible.
- No music-player UI, ornamental chart clutter or fake live market states.
